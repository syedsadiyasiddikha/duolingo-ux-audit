Project Name: Duolingo User Journey and Wireframes Adaptation
1. User Journey Path:
 Home Dashboard → Taps "Start Lesson" → Completes Word Translation →
 Correct answers show Green Banner / Wrong answers show Red Banner (loses 1 heart) → Finishes lesson to see Streak/XP Screen.
2.  Mobile-First Wireframes Included:Home Screen (Path nodes, top status trackers, bottom bar)
    Interactive Lesson Screen (Progress bar, character speaker, clickable word blocks)Ending Victory Screen (XP rewards & daily streak counter)
 3. Desktop Web Adaptation:The mobile bottom bar is moved to a permanent fixed left navigation panel.
    Leaderboards and active daily goals are displayed inside a dedicated right-side panel layout to optimize large desktop screen space.
